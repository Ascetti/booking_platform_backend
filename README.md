# Платформа бронирования с возможностью интеграции с Битрикс24.

Использованные технологии: Laravel, Vue.js, PostgreSQL

## Реализованные задачи:
- Разработана система управления отелем (PMS), позволяющая управлять настройками отеля, номерным фондом, тарифами и ценами, дополнительными услугами, гостями и бронированиями. Также реализован интерактивный календарь для просмотра и управления бронированиями.
- Разработан встраиваемый виджет онлайн-бронирования для размещения на сайтах отелей.
- Спроектировано и реализовано REST API для взаимодействия клиентской и серверной частей системы.
- Реализована серверная бизнес-логика системы управления отелем и процесса бронирования.
- Разработан модуль идентификации и доступа (авторизация, разграничение доступа между отелями, проверка прав при запросах).
- Разработан модуль интеграции с Битрикс24, позволяющий создавать контакты для гостей и сделки для бронирований, а также синхронизировать изменения.

В данном репозитории представлен backend проекта
- Frontend: https://github.com/Ascetti/booking_platform_frontend
- Встраиваемый виджет: https://github.com/Ascetti/booking_platform_booking_widget
